# Somnus UI Kit

A pixel-fidelity recreation of the Somnus Sovereign Systems chat workspace — sidebar nav, multi-modal composer, gradient hero greeting, project bubbles, and a persistent status footer.

**Sources:** `html_reference_images/somnus_main_ui.html`, `App HTMLs/somnus_dashboard.html`, `html_reference_images/multi_agent_collab_ui.html`.

## Components

- `Sidebar.jsx` — Workspace + Sovereign sections with active state
- `Composer.jsx` — Multi-modal composer with voice/camera/send
- `WelcomeHero.jsx` — Gradient text greeting + bubble nav
- `MessageThread.jsx` — User + agent messages with role colors
- `StatusFooter.jsx` — Persistent ops status bar
- `App.jsx` — Glues everything into the index.html prototype
