# REM-Core UI Kit

Pixel-fidelity recreation of the **Recursive Execution Monitor** — strategic intelligence command surface. Hex grids, threat-classified entity panels, system-status HUD, and an orbital-style data console.

**Sources:** `templates/remfinal.html`, `templates/rem_unified_command_center.html`, `templates/satellite_threat_detection.html`, `templates/unified_intelligence_dashboard.html`.

## Components

- `CommandHeader.jsx` — System status bar with HUD top-rule
- `ThreatTicker.jsx` — Scrolling intel ticker
- `EntityPanel.jsx` — Corporate-influence entity card with corner brackets
- `MetricGrid.jsx` — Tabular numeric stat block
- `SystemStatus.jsx` — Right-rail GPU / latency / signal panel
- `App.jsx` — Glues into the index.html prototype
